搜绎是一个智能检索助手。
多角度追问盘问 · 多搜索引擎并发 · 内容相关度多维判定。

输入「考研人数」「如何做决策」，它会先帮你把问题拆细、列维度，再去 Bing/百度/微信公众号/学术数据库抓取，最后只把 真的相关 的文章摆在你面前。

示意图（实际界面更丰富）

核心能力

五个维度，
把含糊问题理细。

多角度追问

5 张盘问卡片（核心指向 / 时间窗 / 立场 / 用途 / 范围），含多选 + 互斥分组。

11 个数据源并发

Bing · 百度 · 微信 · 头条 · OpenAlex 学术 · GitHub 代码等，单次搜索并发拉取。

3 档相关度过滤

严格 80% · 平衡 60% · 宽松 30%。用户自选档位，⚠️ 边缘结果带警告标签。

一手 / 二手溯源

每条结果标注权威等级（gov.cn / 自媒体 / PDF / 学术），可一键导出 Markdown 笔记。

SQLite 历史 + 点击埋点

搜索过的都能回看；点过的链接会被记住，下次搜索时优先排前面。

本地优先

所有数据存本地 SQLite，无云端依赖。隐私安全，跑在你自己电脑上。

本地运行

5 分钟跑起来。

需要 Python 3.10+。Windows 用户有专属脚本。

01

克隆仓库

git clone https://github.com/Wjh202694/AI-.git
cd AI-/search-agent
02

安装依赖

pip install -r requirements.txt
03

启动服务

python main.py

Windows 用户可直接双击 run.bat。浏览器自动打开 http://127.0.0.1:8321/。

04

开始用

输入问题 → 5 张盘问卡片 → 检索方案 → 执行搜索。3 档相关度可随时切换。

提示：首次运行会自动打开浏览器。访问 127.0.0.1:8321 是本机专用，不会发送到任何云端。

搜绎 (Souyi) - 本地使用说明
================================

## 第一次使用

1. 双击 `install.bat`，等 1-2 分钟装依赖
2. 双击 `搜绎.bat`，会自动打开浏览器

## 之后每次使用

直接双击 `搜绎.bat`：
- 自动检测 Python + 依赖
- 后台启动服务（不挡你工作）
- 自动打开浏览器到 http://127.0.0.1:8321/

## 关闭服务

双击 `stop.bat`，或直接：
- 任务管理器 → 找到 `python.exe`（标题"搜绎"）→ 右键结束任务

## 文件说明

| 文件 | 作用 |
|---|---|
| 搜绎.bat | 主入口，双击启动 |
| stop.bat | 停止服务 |
| install.bat | 一次性安装依赖 |
| start-bg.vbs | 后台启动器（搜绎.bat 调用） |
| run.bat | 老式启动脚本（保留兼容） |
| main.py | 程序入口 |
| backend/ | 后端代码 |
| frontend/ | 前端代码 |
| data/ | 搜索历史（SQLite，不上传云端） |
| requirements.txt | Python 依赖列表 |

## 端口冲突

搜绎默认用端口 8321。如果被占用，会自动尝试 8322 / 8323。

## 常见问题

Q: 双击 搜绎.bat 没反应？
A: 看 cmd 窗口里的报错。最大可能是 Python 路径不对，编辑 搜绎.bat 修改 PYTHON 变量。

Q: 浏览器没自动打开？
A: 手动访问 http://127.0.0.1:8321/

Q: 搜不到东西？
A: 检查网络。一些搜索引擎（如 DuckDuckGo / Brave）国内连不通，正常。

## 卸载

直接删除整个项目目录即可。没有任何注册表残留、后台服务、系统钩子。

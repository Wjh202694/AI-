# 搜绎 - 浏览器扩展

> 把含糊的问题，理成能搜的话。

搜绎是一个**纯本地**的浏览器扩展（Manifest V3）：在任意网页选中含糊问题 → 一键生成多角度检索方案 → 复制到搜索引擎粘贴。

## 功能

- 🪄 **任意网页选中文字** → 右键「用搜绎生成检索方案」→ 侧边栏弹出
- ❓ **5 张追问卡片**：核心指向 / 时间窗 / 立场 / 用途 / 范围（多选 + 卡内互斥）
- 📋 **5 组检索式**：原始问句 / 拆词组合 / 高级指令 / 站点定向 / 反面搜索
- 📑 **复制全部 / 复制 JSON**：直接粘贴到 Bing/百度/学术库等
- 🌗 **深色模式自适应**

## 安装（开发者模式）

1. 打开浏览器（Chrome 121+ / Edge 121+）
2. 地址栏输入 `chrome://extensions/`
3. 右上角打开 **"开发者模式"**
4. 点 **"加载已解压的扩展程序"**
5. 选择本 `extension/` 目录

安装后浏览器工具栏会出现 **S** 图标，点击打开右侧搜绎侧边栏。

## 使用

### 方式 1：选中文本（推荐）

1. 在任意网页选中一段文字（"考研人数"、"如何做决策"……）
2. 右键 → **「用搜绎生成检索方案」**
3. 侧边栏弹出，问题已自动填入
4. 点 **「生成检索方案 →」**
5. 5 张追问卡片 → 选择/填空 → 点 **「据此生成方案 →」**
6. 勾选想要的检索式 → 点 **「复制全部检索式」**
7. 粘贴到 Bing/百度/微信搜一搜/学术库

### 方式 2：手动输入

1. 点击工具栏的 **S** 图标
2. 在侧边栏输入问题
3. 同上步骤 4-7

### 方式 3：快捷键

- **Alt+S**：打开搜绎侧边栏（任意页面）

## 文件结构

```
extension/
├── manifest.json          # 扩展清单（V3）
├── icons/                  # 16/32/48/128 图标
├── sidepanel.html          # 主界面
├── sidepanel.css
├── sidepanel.js            # 主逻辑（拆词 + 渲染 + 复制）
├── background.js           # Service Worker（右键菜单 + 工具栏点击）
├── content.js              # 内容脚本（捕获选中文字）
├── lib/
│   ├── plan.js             # 拆词 + 检索矩阵（JS 重写）
│   ├── clarifier.js        # 追问卡片（JS 重写）
│   └── jargon.js           # 黑话映射 + 停用词
└── README.md
```

## 技术细节

- **零后端依赖**：所有逻辑都在浏览器里跑
- **零云端请求**：不上传任何数据
- **兼容 Chrome / Edge / Firefox**：标准 Manifest V3 + Side Panel API
- **核心算法**：约 200 行 JS（从 Python 后端翻译）

## 与桌面版的区别

| 功能 | 浏览器扩展 | 桌面版（FastAPI） |
|---|---|---|
| 生成检索方案 | ✅ | ✅ |
| 多角度追问 | ✅ | ✅ |
| **实际搜索** | ❌ 复制到引擎 | ✅ 自动并发 |
| 内容相关度判定 | ❌ | ✅ |
| 搜索历史 | ❌ | ✅ SQLite |
| 点击量排序 | ❌ | ✅ |

**设计理念**：扩展负责"理清问题 + 生成方案"，搜索动作由用户复制后到喜欢的引擎去搜。

## 调试

打开扩展的 service worker 控制台：
1. `chrome://extensions/` → 找到搜绎 → 点 **"service worker"**
2. 查看 background.js 日志

侧边栏调试：右键侧边栏 → **"检查"**

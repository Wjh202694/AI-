# web-avatar-subagent

以 Subagent 思路为核心的网页端任务替身。自动把资料搜索、调研、长文本分析、方案比较、蒸馏推理等**重型子任务**交给独立子代理处理，主会话只拿结论。

## 触发场景

- 需要联网搜索／调研／长文本分析／方案比较等重型子任务
- 想把繁重推理外包给独立子代理以节省主会话 token
- 需要在网页端代替用户执行操作（登录／填表／抓取／发布）

## 两种模式（先判定再选）

1. **委派模式**——把重型子任务派给独立子代理，主会话只接收结论
2. **浏览器执行**——在网页端替用户执行实际操作

## 委派判定

触发条件驱动：任务是否足够重、结果是否只需结论、是否可与主线并行。策略上支持**并行与复用**——同类型子任务不重复派发。

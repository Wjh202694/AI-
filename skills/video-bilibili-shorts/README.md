# video-bilibili-shorts

社媒短视频（侧重 B 站）制作流水线。把文案／主题转成带**中英双语字幕**、风格贴合的短视频，输出无配音成片与真人配音文案。

## 触发场景

- 制作要发布到 B 站的短视频
- 需要中英双语字幕且字幕贴合内容风格
- 同时需要无配音视频 + 真人配音文案
- 用户提到 bilibili / B 站 / 短视频投稿

## 流水线

文案／主题 → 素材准备 → 混剪 → 转场 → 双语字幕（中文 + 英文）→ 成片输出 → 配音文案单独交付。

## 关键规则

- 字幕必须贴合内容风格，非通用模板套用
- 无配音成片与真人配音文案分别交付，二者风格需一致

## 环境依赖 + 降级

主流程依赖 `scripts/pipeline.sh` 串联；外部工具缺失时有降级路径（见 SKILL.md「环境依赖 + 降级」章节）。

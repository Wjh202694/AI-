# skill-router

通用技能调用器（Skill Router）。**不执行任务本身**，只负责在动手前为任务找到正确的技能——把用户请求原样转交到技能星图（Skill Atlas）分析，返回匹配的技能。

## 触发场景

- 用户点名：「用调用器」「skill-router」「先帮我选技能」
- 任务中出现「推荐技能」「该用什么 skill」「有没有现成技能」意图
- 把本 skill 设为默认首步时，任何新任务先经过它

## 行为约定（严格）

- 只路由，不执行
- 请求原样转交，不擅自改写用户意图
- 返回匹配结果后交回主导权

## 输出格式

路由结果 + 匹配到的技能清单 + 建议的下一步。

## 文件结构

```
skill-router/
└── SKILL.md    # 触发条件、行为约定、输出格式、边界
```

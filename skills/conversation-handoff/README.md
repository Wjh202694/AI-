# conversation-handoff

多轮对话的**目标判断与交接中枢**。按需工具，非常驻：帮你确认开局目标、检测多轮中的目标漂移、在技能／场景切换时无损交接上下文。

## 触发场景

- 任务开始时需要确认目标是否正确
- 多轮对话跑偏了，需要判断是否该新开对话
- 需要在技能间／场景间无损交接上下文
- 触发词：对话交接、目标确认、任务跑偏、新开对话、上下文交接、总结前文

## 核心机制

1. **开局目标判断 + 确认**——任务开始时先对齐目标，不默认用户意图
2. **漂移检测清单**——每轮检查当前任务是否已偏离原始目标（可被宿主 hook 复用）
3. **新开对话建议**——判定何时应该重开，而不是在污染的上下文里硬撑
4. **交接包生成 + 落盘 + 续接**——生成结构化交接摘要并可落盘，供下一次对话续接

## 重要边界

- 是**按需工具**，非常驻：不开启时完全不介入
- 不自动改写历史结论，只做判断与交接
- 用户说「重新开始」时全部推演作废

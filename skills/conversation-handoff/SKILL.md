# 对话交接（按需工具，非常驻）

## 重要边界
本 skill 是**按需加载**的：只在被触发时执行「生成交接包」「跑漂移检查清单」。**常驻监测（每轮判断目标、每轮检测漂移）属于宿主常驻能力**，应提升为宿主 hooks 或常驻规则；本 skill 提供「漂移检测清单」供其直接复用（见协议 2 与附录 B）。不在宿主里时，漂移检查只能由主会话在合适时机主动调用本 skill 触发。

## 功能定位
对话层的「目标确认 + 交接」工具：开局提炼目标请用户确认；需要时检测目标漂移并建议新开对话；把前文思考总结成**可落盘、带产物路径**的结构化交接包。

## 何时使用
- 任务启动，需要先把目标对齐再动手
- 长多轮后怀疑跑偏，需要判断是否开新对话
- 跨会话/跨技能交接，要求不丢目标、不丢产物

## 协议

### 1. 开局：目标判断 + 确认
- 提炼「我认为你的目标是：…」，用 2–4 个关键问题请用户确认是否正确。
- 状态 A（需澄清）：只输出关键问题，不给未确认定稿、不给长篇分析。
- **自主模式默认策略**：若一轮无回应（自主运行/用户离线），按当前理解**直接执行**，并在输出中明确标注「所做假设」。不卡死等待。

### 2. 漂移检测清单（可供宿主 hook 复用，见附录 B）
命中以下信号即判定可能偏移，主动提醒：
定性信号：
- 连续多轮后讨论主题与原目标显著不同
- 出现多个并列、互不归属的子目标
- 上下文已过长、关键约束被稀释或遗忘
- 用户开始讨论与原任务无关的新话题
可判定信号（供程序化 hook）：
- 单任务工具调用超过 20 次仍无收敛产物
- 宿主触发上下文压缩（context compaction）
- 主会话已切换至与原目标无关的新 top-level 任务

### 3. 新开对话建议
漂移明显时，提示「建议新开对话处理 X，我先把当前思考总结如下」，并给出交接包，不强行在原会话混跑。

### 4. 交接包生成 + 落盘 + 续接
- 严格按附录 A 模板填写。
- **落盘规则**：写入 `handoff/YYYY-MM-DD-<主题>.md`（相对当前工作区；目录不存在则创建）。同时把路径回传给用户/主会话。
- 必含字段：`artifacts`（产物文件绝对/相对路径）、`open_questions`、`assumptions`、`owner`。
- **续接协议（新会话如何发现）**：落盘后在返回消息中给出「新会话开局指引」——新会话启动时，主会话应**先检查工作区 `handoff/` 目录的最新文件**，若存在且主题相关，优先读取并以之作为上下文起点。也可在宿主常驻规则中固化此检查（见附录 B）。

## 输入
- 当前对话上下文、任务目标、约束、已完成/未完成项、产物路径

## 输出
- 开局：目标确认提问（状态 A：只问关键问题）
- 进行中：漂移提醒 + 新开对话建议
- 交接：`handoff/YYYY-MM-DD-<主题>.md` + 同内容 Markdown 摘要

## 环境依赖 + 降级
- 依赖：文件系统写入（落盘交接包）。
- 缺失/不可写时：降级为「仅聊天流内输出交接包摘要」，并**明确提示用户手动保存**，不得假装已落盘。

## 验收标准
- 交接包 9 字段（summary/done/todo/constraints/open_questions/assumptions/artifacts/next/owner）齐全且非空。
- `artifacts` 中列出的路径真实存在。
- `owner` 取值为「用户 / 新对话 / 主会话（将调用 skill:xxx）」之一，不得填 skill 名本身。
- 落盘路径已回传且含续接指引；或降级时已明确告知未落盘。

## 协作（给主会话的指令）
- 重型子任务（搜索/调研/长文分析/方案对比）建议主会话调用 skill: web-avatar-subagent（网页替身）派生子代理。
- 视频成品发布 B站、UI 产出真实浏览器验证，分别由主会话调用 skill: video-bilibili-shorts（B站短视频制作）/ skill: ui-award-design（获奖级 UI 设计）处理。

## 附录 A：对话交接包模板（复制即用）

```markdown
# 对话交接包：<主题>

- **summary**: <已确认目标与背景，2–4 句>
- **done**: <已完成关键结论，要点列表>
- **todo**: <待办，标注归属（新对话 / 本会话）>
- **constraints**: <硬性约束，如中文规范、平台、风格>
- **open_questions**: <尚未确认、需对方决策的问题>
- **assumptions**: <本次自主推进所做假设>
- **artifacts**: <产物文件路径，绝对或相对路径列表；无则写「无」>
- **next**: <下一步建议，明确可执行第一步>
- **owner**: <接收方：用户 / 新对话 / 主会话（将调用 skill:xxx）>
```

> 落盘位置：`<工作区>/handoff/YYYY-MM-DD-<主题>.md`
> 新会话读取此文件即可无损续接，无需重述前文。
> 续接：新会话开局先查 `handoff/` 目录最新文件，主题相关则以其为上下文起点。

## 附录 B：宿主常驻规则文本（可直接粘贴）
将以下规则加入宿主常驻规则 / hooks，使漂移检测成为常驻能力（本 skill 仅按需执行，不常驻）：

```
每轮对话结束时：
1. 用 conversation-handoff 的「漂移检测清单」评估当前会话；
2. 若命中任一可判定或定性信号，向用户提示「任务可能已偏移，建议新开对话并用对话交接整理前文」；
3. 任务开局时，先检查工作区 handoff/ 目录是否存在与当前主题相关的交接包；若有，将其作为上下文起点。
```
